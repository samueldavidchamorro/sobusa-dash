# SOBUSA · Dash de sustentación

Pronóstico de la demanda de pasajeros por tramo de 500 m y por hora (rutas 2, 16 y 21 de SOBUSA, Barranquilla), emitido a las 04:00.

- `index.html`: el Dash completo en un solo archivo. Abre con doble clic y funciona sin internet.
- Avance: ↓ / AvPág / espacio (siguiente), ↑ / RePág (anterior), teclas 1–3 (ir a cada parada).
- Despliegue: Render, sitio estático (`render.yaml`).

Solo contiene resultados agregados del proyecto: no incluye datos personales, credenciales ni datos de la base.
